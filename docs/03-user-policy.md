# 이용자 정책

## 1. 회원가입 정책

### 1.1 필수 정보

| 정보 | 설명 |
|------|------|
| 이메일 | 로그인 ID, 필수 입력 |
| 비밀번호 | 8자 이상, 영문/숫자/특수문자 혼합 |
| 닉네임 | 게시판에서 표시되는 이름, 필수 입력 |
| 프로필 이미지 | 선택 사항 |

### 1.2 소셜 로그인

- 구글, 카카오, 네이버, 깃허브 연동 가능
- 소셜 로그인 시 이메일은 OAuth provider로부터 자동 수집

### 1.3 회원가입 제한

- 동일 이메일 중복 가입 불가
- 닉네임 중복 사용 불가 (다른 사용자와 중복 불가)

---

## 2. 로그인 정책

### 2.1 로그인 방식

| 방식 | 설명 |
|------|------|
| 이메일 | 이메일 + 비밀번호 |
| 소셜 로그인 | 구글/카카오/네이버/깃허브 계정으로 로그인 |

### 2.2 로그인 세션

- JWT 기반 세션 관리
- 세션 만료: 7일 (연장 가능)

---

## 3. 게시글 정책

### 3.1 글 작성 권한

| 사용자 | 권한 |
|--------|------|
| 비회원 | 글 작성 가능 (수정/삭제 불가) |
| 회원 | 글 작성/수정/삭제 가능 |
| 관리자 | 모든 권한 |

### 3.2 비밀글 정책

- 허용 게시판: 자유게시판, 질문게시판
- 작성자와 관리자만 열람 가능
- 비밀번호 불필요 (회원/비회원 식별)

### 3.3 익명글 정책

- 모든 게시판에서 익명 선택 가능
- 익명 선택 시 작성자는 "익명"으로 표시
- 관리자만 실제 작성자 확인 가능
- 익명이라도 신고 시 제재 가능

### 3.4 공지글 정책

- 관리자만 작성/수정/삭제 가능
- 공지글은 게시판 상단에 고정
- 모든 사용자가 열람 가능

---

## 4. 댓글 정책

### 4.1 댓글 작성 권한

| 사용자 | 권한 |
|--------|------|
| 비회원 | 댓글 작성 불가 |
| 회원 | 댓글/대댓글 작성 가능 |
| 관리자 | 모든 권한 |

### 4.2 대댓글

- 댓글에 대한 대댓글만 허용 (1단계 depth)
- 대댓글도 일반 댓글과 동일한 규칙 적용

---

## 5. 좋아요 정책

- 회원만 좋아요 가능
-同一 사용자가同一 대상에 좋아요는 1회만 가능
- 좋아요 취소 가능

---

## 6. 신고 정책

### 6.1 신고 대상

- 게시글
- 댓글

### 6.2 신고 가능 사용자

- 회원 (본인 작성 내용은 신고 불가)

### 6.3 신고 사유

- 욕설/비방
- 스팸/광고
- 불건전한 내용
- 개인정보 노출
- 기타 (직접 입력)

### 6.4 신고 누적 처리

| 누적 횟수 | 처리 |
|-----------|------|
| 1~4회 | 관리자가 내용 검토 |
| 5회 | 자동 숨김 처리 |

### 6.5 관리자 검토

- 숨김 처리된 글은 관리자가 검토
- 적절한 경우 복원, 부적절한 경우 영구 삭제
- 신고한 사용자에게 처리 결과 알림 (개선 사항)

---

## 7. 사용자 차단 정책

### 7.1 관리자의 사용자 차단

- 관리자가 회원을 차단할 수 있음
- 차단된 회원은:
  - 글 작성 불가
  - 댓글 작성 불가
  - 로그인 불가 (접근 불가)

### 7.2 차단의 해제

- 관리자가 언제든지 차단 해제 가능

---

## 8. 북마크 정책

- 회원만 사용 가능
- 북마크 추가/제거는 본인이 언제든지 가능
- 마이페이지에서 북마크 목록 확인

---

## 9. 파일 업로드 정책

### 9.1 허용 파일 형식 및 크기

| 종류 | 확장자 | 최대 크기 |
|------|--------|-----------|
| 이미지 | jpg, png | 5MB |
| 문서 | pdf, docx, hwp, xlsx, zip | 10MB |

### 9.2 자료실 업로드

- 관리자만 업로드 가능
- 모든 사용자가 다운로드 가능 (로그인 필요)

---

## 10. 개인정보 보호

### 10.1 익명성

- 익명글은 "익명"으로 표시
- 관리자를 제외한 타인은 작성자를 알 수 없음

### 10.2 관리자의 개인정보 접근

- 관리자는 신고 처리 등을 위해 실제 작성자 확인 가능
- 관리자의 개인정보 접근은 내부적으로 기록됨
