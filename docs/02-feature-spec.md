# 기능 명세서

## 1. 인증 (Authentication)

### 1.1 회원가입

| 필드 | 필수 | 설명 |
|------|------|------|
| 이메일 | ✅ | 로그인 ID로 사용 |
| 비밀번호 | ✅ | 8자 이상, 영문/숫자/특수문자 혼합 |
| 닉네임 | ✅ | 게시판에서 표시되는 이름 |
| 프로필 이미지 | ❌ | 선택 사항, 업로드 가능 |

### 1.2 로그인

| 방식 | 설명 |
|------|------|
| 이메일 로그인 | 이메일 + 비밀번호 |
| 소셜 로그인 | 구글, 카카오, 네이버, 깃허브 |

### 1.3 소셜 로그인 연동

| provider | 필요 정보 |
|----------|-----------|
| Google | Google 계정 |
| Kakao | Kakao 계정 |

| GitHub | GitHub 계정 |

## 2. 게시판 기능

### 2.1 게시판 목록

| 게시판 | 설명 | 권한 |
|--------|------|------|
| 자유게시판 | 자유로운 글 작성 | 비회원 글 작성, 회원 전체 |
| 공지사항 | 사이트 공지 | 관리자만 작성 |
| 질문게시판 | Q&A 형식 | 전체 |
| 자료실 | 파일 공유 | 관리자만 업로드 |

### 2.2 글쓰기

**공통 필드:**

| 필드 | 설명 |
|------|------|
| 제목 | 필수, 최대 100자 |
| 내용 | 필수, 최대 10,000자 |
| 게시판 선택 | 필수 |
| 글 종류 | 일반 / 공지 / 비밀 / 익명 |
| 파일 첨부 | 선택, 다중 업로드 가능 |

**비밀글 옵션:**

- 질문게시판, 자유게시판에서만 허용
- 비밀글은 작성자와 관리자만 열람 가능
- 비밀번호 설정 불필요 (회원/비회원 식별으로 관리)

**익명글 옵션:**

- 익명 선택 시 작성자 이름 "익명"으로 표시
- 관리자는 실제 작성자 확인 가능

### 2.3 글 수정/삭제

| 구분 | 회원 | 비회원 |
|------|------|--------|
| 수정 | ✅ 본인의 글만 | ❌ 불가 |
| 삭제 | ✅ 본인의 글만 | ❌ 불가 |

- 삭제 시 ** мягкий 삭제 (soft delete)**: DB에서 즉시 삭제하지 않고 삭제 표시

### 2.4 글 조회

- 제목, 내용, 작성자, 작성일, 조회수, 좋아요 수 표시
- 첨부파일 목록 표시 (다운로드 가능)
- Secret 글은 작성자/관리자만 열람 가능

## 3. 댓글 기능

### 3.1 댓글 작성

- 회원만 댓글 작성 가능
- 원글에 종속되는 구조

### 3.2 대댓글

- 댓글에 대한 답변 형식
- 최대 depth: 1단계 (댓글의 댓글까지)
- 대댓글도 회원만 작성 가능

### 3.3 좋아요

| 대상 | 가능 사용자 |
|------|------------|
| 글 | 회원 |
| 댓글 | 회원 |

- 한 사용자가同一 대상에 대해 좋아요는 1회만 가능
- 취소 가능

### 3.4 신고

| 대상 | 가능 사용자 |
|------|------------|
| 글 | 회원 |
| 댓글 | 회원 |

신고 사유 선택:
- 욕설/비방
- 스팸/광고
- 불건전한 내용
- 개인정보 노출
- 기타

## 4. 검색 기능

### 4.1 검색 범위

- 제목 + 내용 + 작성자

### 4.2 검색 필터

- 게시판별 필터링
- 기간별 필터링 (오늘, 1주일, 1개월, 1년, 전체)

### 4.3 검색 결과

- 제목, 내용 미리보기 (일부), 작성자, 작성일
- 해당 게시판으로 바로 이동

## 8. 관리자 기능

### 8.1 관리자 대시보드

| 항목 | 설명 |
|------|------|
| 회원 수 | 전체 회원 수, 오늘 신규 회원 |
| 게시글 수 | 전체 게시글 수, 오늘 작성된 글 |
| 신고 현황 | 미처리 신고 수, 누적 신고 글 |
| 인기 게시글 | 조회수 Top 5, 좋아요 Top 5 |

### 8.2 게시판 관리

- 공지글 등록/수정/삭제
- 게시글 삭제 (회원 글도 관리자가 삭제 가능)

### 8.3 회원 관리

- 회원 목록 조회
- 회원 차단/해제
- 회원 정보 열람 (실제 익명 작성자 확인)

### 8.4 신고 관리

- 신고 목록 조회
- 신고 내용 검토
- 해당 글/댓글 삭제 또는 복원
- 신고 누적(5회)된 글 자동 숨김 처리

---

## 9. 운영 정책

### 9.1 신고 누적 처리

| 누적 횟수 | 처리 |
|-----------|------|
| 1~4회 | 관리자가 내용 검토 |
| 5회 이상 | 자동 숨김 처리 |

숨김 처리 후:
- 관리자가 검토하여 복원 또는 영구 삭제 결정

### 9.2 익명 정책

- 익명 글은 작성자가 "익명"으로 표시
- 관리자는 특별한 기능으로 실제 작성자 확인 가능
- 익명 게시판에서도 신고 가능, 누적 시 제재 적용
