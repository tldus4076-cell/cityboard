# 서비스 개요

## 1. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 프로젝트명 | CityBoard (가칭) |
| 프로젝트 유형 | 커뮤니티 게시판 웹사이트 |
| 개발 형태 | 개인 프로젝트 |
| 주요 사용자 | 일반 사용자, 학생 |

## 2. 서비스 목적

이 서비스는 다음 기능을 종합적으로 제공하는 **커뮤니티 게시판 플랫폼**입니다:

- **커뮤니티**: 자유로운 소통과 정보 공유
- **공지사항**: 중요 정보를 사용자에게 전달
- **Q&A**: 질문과 답변을 통한 상호 도움
- **익명 게시판**: 익명성을 보장받은 자유로운 표현 공간

## 3. 주요 기능 요약

### 3.1 게시판

| 게시판명 | 설명 | 사용 권한 |
|----------|------|-----------|
| 자유게시판 | 일반적인 자유로운 글 작성 | 비회원, 회원, 관리자 |
| 공지사항 | 사이트 공지 및 중요 안내 | 관리자만 작성 |
| 질문게시판 | Q&A 형식의 질문과 답변 | 비회원, 회원, 관리자 |
| 자료실 | 파일/자료 공유 공간 | 관리자만 업로드 가능 |

### 3.2 글 종류

- **일반 글**: 작성자 이름 공개
- **공지글**: 관리자가 등록하는 중요 안내 (상단 고정)
- **비밀글**: 작성자와 관리자만 내용 확인 가능
  - 허용 게시판: 자유게시판, 질문게시판
- **익명글**: 작성자 정보 비공개
  - 관리자만 실제 작성자 추적 가능

### 3.3 댓글 기능

- 기본 댓글 작성
- 대댓글 (댓글에 대한 답변)
- 좋아요 (글/댓글에 대한 호감 표현)
- 신고 (부적절한 내용 신고)

### 3.4 검색

- 검색 범위: 제목 + 내용 + 작성자
- 게시판별 필터링 검색 가능

### 3.5 파일 업로드

**허용 파일 형식:**

| 종류 | 확장자 |
|------|--------|
| 이미지 | jpg, png |
| 문서 | pdf, docx, hwp, xlsx, zip |

## 4. 사용자 권한

| 권한 등급 | 가능 操作 |
|----------|-----------|
| **비회원** | 글 작성 (수정/삭제 불가) |
| **회원** | 글 작성/수정/삭제, 댓글, 좋아요, 신고, 북마크 |
| **관리자** | 모든 회원 操作 + 글 삭제, 사용자 차단, 신고 처리, 공지 등록, 자료실 업로드 |

## 5. 로그인 방식

- **이메일 로그인**: 이메일 + 비밀번호로 회원가입/로그인
- **소셜 로그인**: 구글, 카카오, 네이버, 깃허브

## 6. 운영 정책

### 6.1 신고 처리

- 사용자가 부적절한 내용을 신고
-同一 게시글이 **5회 신고** 누적 시 **자동 숨김 처리**
- 관리자가 신고 내용 검토 후 복원 또는 영구 삭제 결정

### 6.2 관리자 대시보드

관리자 페이지에서 다음 정보를 확인할 수 있음:

- 회원 수 현황
- 게시글 수 현황
- 신고 현황
- 인기 게시글 (조회수/좋아요 기준)

## 7. 비회원 정책

- 비회원은 **글 작성만 가능**
- 비회원 글은 수정/삭제 불가
- 댓글 작성 불가 (회원만 가능)
