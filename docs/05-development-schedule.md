## 5. 기술 검증 (PoC)

### 1주차에 검증할 항목

| 항목 | 검증 내용 |
|------|-----------|
| NextAuth + 소셜 로그인 | 구글/카카오 로그인 정상 동작 확인 |
| Prisma + PostgreSQL | DB 연결, CRUD 정상 동작 확인 |
| 파일 업로드 | Supabase Storage 또는 S3 업로드/조회 확인 |
| 익명/관리자 확인 | 익명 처리 및 관리자 권한 동작 확인 |

## 6. 리스크 및 대응

| 리스크 | 가능성 | 대응 |
|--------|--------|------|
| 소셜 로그인 OAuth 설정 복잡 | 중간 | 각 Provider 문서 참고, 테스트 계정 준비 |
| 파일 업로드 용량 제한 | 낮음 | Supabase/S3 활용, 클라이언트에서 미리 검증 |
| 익명 처리 보안 | 중간 | 관리자만 실제 작성자 확인 가능하도록严格한 권한 관리 |
| 성능 (대규모 데이터) | 낮음 (초기) | 인덱스 설정, 페이지네이션으로 대응 |
